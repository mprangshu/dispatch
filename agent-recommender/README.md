# Agent Recommender & Q&A Chatbot

A chatbot over a catalog of AI agents — usable from the CLI, an HTTP API, or a
Streamlit web UI: it recommends the best-fitting agent for a described need and
answers questions about agents, grounded strictly in their Markdown docs (no
fabricated facts).
